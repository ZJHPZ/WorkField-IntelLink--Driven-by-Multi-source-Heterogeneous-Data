# 职域智联 · 个人侧前端设计方案

> 设计语言：深空战舰（Dark Space Battleship）—— 继承自「数知」设计体系
> 独立项目：职业规划助手（To C）—— 个人技能导航工具
> 技术栈：Vue 3 + TypeScript + Vite + Pinia + Tailwind CSS 3 + ECharts + markdown-it + KaTeX

---

## 1. 设计理念

### 1.1 一句话设计定位

> 用户打开页面，看到的是**一个属于自己的星图**——他的技能是恒星。目标岗位是星座。差距是暗物质。学习路径是穿越星海的航线。每掌握一项技能，星图上就点亮一颗新的星。

### 1.2 核心视觉隐喻

| 页面元素 | 视觉隐喻 | 设计来源 |
|---------|---------|---------|
| 背景 | 广袤的个人知识宇宙——星空 + 柔和星云 | `CosmicBackground.vue` |
| 用户技能 | 发光的恒星——每项技能一颗星，亮度=市场需求 | `ProfileStar3D` 概念简化 |
| 目标岗位 | 目标星座——由多个技能构成的连线图案 | 知识图谱 `PlanetNode` |
| 匹配率 | 圆环进度——SVG 靛蓝→紫→青渐变环 | `ProgressRing.vue` |
| 缺失技能 | 暗物质——红/琥珀色标记的灰暗区域 | `StageCard` locked 态 |
| 学习路径 | 星际航线——从当前星到目标星的有向路径 | 路线图概念 |
| 技能保鲜 | 灯塔光束——绿色到玫瑰色渐变，高度=健康度 | `FocusLighthouse.vue` |
| AI 分析中 | "心率脉冲"——靛蓝 box-shadow 呼吸 | `heartbeat-pulse` keyframe |

## 3. Pinia Store 设计

### 3.1 `stores/personal.ts`

```typescript
interface PersonalState {
  // 用户
  userId: string
  profile: UserSkillProfile | null

  // 技能画像
  skills: UserSkill[]
  totalSkillCount: number
  growthSinceFirst: {
    firstCount: number
    currentCount: number
    netGain: number
    firstUpload: string
  }

  // 人岗匹配
  currentMatch: {
    positionId: string
    positionName: string
    matchRate: number
    matchedSkills: string[]
    partialSkills: string[]
    missingSkills: MissingSkill[]
    learningPath: LearningStep[]
  }
  compareMatches: CompareResult[]   // 多岗位对比

  // 技能保鲜
  freshnessAlerts: FreshnessAlert[]
  healthySkills: string[]

  // 转行分析
  switchAnalysis: SwitchFeasibility | null

  // 成长轨迹
  growthTimeline: GrowthNode[]
  levelProgression: LevelProgression

  // Agent 状态
  agentStatusMessages: string[]

  // 加载态
  loading: Record<string, boolean>
}
```
