# 职域智联 · 企业侧前端设计方案

> 设计语言：深空战舰（Dark Space Battleship）—— 继承自「数知」设计体系
> 独立项目：企业工作台（To B）—— 岗位标准智能管理平台
> 技术栈：Vue 3 + TypeScript + Vite + Pinia + Tailwind CSS 3 + AntV G6 + ECharts

---

## 1. 设计理念

### 1.1 一句话设计定位

> HR 打开页面，看到的是**一个会呼吸的指挥中心**——深色的宇宙背景上，岗位数据以辉光、脉冲、进度环的方式呈现。每一条数据变化都有视觉痕迹。每一个决策都有数据支撑。

### 1.2 核心视觉隐喻

| 页面元素 | 视觉隐喻 | 设计来源 |
|---------|---------|---------|
| 背景 | 深空星云——三层 radial-gradient + 程序化星空 | `CosmicBackground.vue` |
| 岗位标准 | 稳定的"恒星"——品牌色实线 + confirmed 辉光 | `StageCard` completed 态 |
| 市场变化 | 运动的"星尘"——青色强调色 + 上升箭头 ↑ | HUD 状态条 |
| 技能衰退 | 暗去的"星辰"——玫瑰色标记 + opacity-60 | `StageCard` locked 态 |
| 新岗位发现 | 爆发的"新星"——彩纸粒子庆祝 | `StageCompleteModal` |
| AI 处理中 | "心率脉冲"——靛蓝 box-shadow 呼吸 | `heartbeat-pulse` keyframe |

## 3. Pinia Store 设计

### 3.1 `stores/enterprise.ts`

```typescript
interface EnterpriseState {
  // 仪表板 HUD 数据
  dashboard: {
    managedPositionCount: number
    pendingCandidates: number
    jdPassRate: number
    marketChangeAlerts: number
    teamCoverage: number
    lastUpdated: string
  }

  // 岗位标准列表
  positions: PositionStandard[]

  // 当前选中岗位的详情
  currentPosition: {
    standard: PositionStandard | null
    marketReality: MarketSkillSet | null
    diff: StandardDiff | null
    timeline: EvolutionNode[]
  }

  // 新岗位发现
  candidates: RoleCandidate[]
  debateState: {
    proArgument: object | null
    conArgument: object | null
    verdict: object | null
  }

  // JD 诊断
  diagnosisResults: JDDiagnosis[]
  batchAuditProgress: number

  // 团队盘点
  teamGapReport: TeamGapReport | null

  // 人才预测
  forecast: {
    emerging: SkillTrend[]
    cooling: SkillTrend[]
  }

  // 图谱
  graphData: { nodes: any[]; edges: any[] }

  // Agent 状态文案
  agentStatusMessages: string[]

  // 加载态
  loading: Record<string, boolean>
}

// ★ 关键模式：API 静默回退到演示数据
// 每个 action 都遵循:
//   try { data = await api.get() } catch { data = demoData }
```

## 5. 动画规范

| 场景 | 动画 | 时长 | 缓动 |
|------|------|------|------|
| 页面切换 | 弹性缩放 + 向上平移 | 0.4s | `cubic-bezier(0.34, 1.56, 0.64, 1)` |
| HUD 数值更新 | 数字递增 + 颜色过渡 | 0.7s | `transition-all` |
| 差异项出现 | 列表交错入场 | 60ms/card | `springIn` keyframe |
| 新岗位确认 | 彩纸粒子 + 弹性缩放 | 1.5s + 0.4s | `confetti-fall` + `cubic-bezier` |
| 通胀指数条 | 从左向右填充 | 0.7s | `transition-all` |
| AI 处理中 | 心率脉冲 box-shadow | 1.5s | `heartbeat-pulse` |
| 卡片悬停 | 上浮 + 光晕增强 | 0.3s | ease-out |
| 图谱节点悬停 | 放大 + 光晕增强 | 0.2s | ease-out |
| 按钮点击 | 涟漪径向渐变 | 0.3s | `btn-ripple` |
