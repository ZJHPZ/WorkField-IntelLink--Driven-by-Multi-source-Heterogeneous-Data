# 前端设计补充：动态演化与可视化增强

> 基于赛题 XH-202621 深度阅读 + 用户"时空动态展示"洞察
> 目标：在静态 demo 数据基础上，将前端可视化表现提升到惊艳程度

---

## 0. 核心设计原则

1. **一切皆可演化** — 不展示"是什么"，展示"如何变成这样"
2. **动画即信息** — 每个动画传达数据变化的方向、速度、幅度
3. **透明可追溯** — 每个数据点标注来源和置信度
4. **对比是本能** — Diff 视图优先于单一视图

## 1. 时间轴驱动的演化引擎

### 1.1 EvolutionTimeline 组件（新增 · 核心组件）

**功能**：可拖拽时间滑块 + 自动播放 + 事件标注

```
┌──────────────────────────────────────────────────────────┐
│  ◄ 2022 ────┬──── 2023 ────┬──── 2024 ────┬── 2026 ►  │
│        ●         ●    ●          ●     ●                 │
│       Q2        Q1   Q3         Q2    Q4                │
│                                                          │
│  ●━━━━━━━━━━━━━━━━━●━━━━━━━━━━━━━━━━━━●  (当前: 2024Q2) │
│                                                          │
│  [▶ 自动播放] 速度: [1x ▾]  [对比模式]                    │
├──────────────────────────────────────────────────────────┤
│  🟢 2024Q2 事件:                                         │
│     + 新增技能 "大语言模型" (来源: 142条JD, 置信度 87%)     │
│     ↑ 升级 "深度学习" 从 advanced → expert                  │
│     ↓ 衰退 "SVM" 市场需求下降 42%                          │
└──────────────────────────────────────────────────────────┘
```

**Props**:
- `timeline: TimelineEvent[]` — 时间线事件数组
- `selectedDate?: string` — 当前选中时间点
- `autoPlay?: boolean` — 是否自动播放
- `speed?: number` — 播放速度倍数

**Events**: `@update:selectedDate`, `@play`, `@pause`

**动画规范**:
- 时间指示器沿轴线滑动：`transition: left 0.3s cubic-bezier(0.4, 0, 0.2, 1)`
- 事件列表交错入场：`spring-list` 标准交错（每个 +60ms）
- 时间点标记 hover 时放大 1.3x + glow

### 1.2 技能节点演化动画

当用户拖动时间轴时，图谱/列表中的技能节点应实时响应：

| 变化类型 | 视觉表现 | CSS 动画 |
|---------|---------|---------|
| 新增技能 | opacity 0→1 + scale 0.8→1 + mint 辉光闪烁 | `springIn` 0.5s |
| 删除技能 | opacity 1→0.3 + scale 1→0.9 + rose 边框 | 过渡 0.4s |
| 升级技能 | mint 脉冲 + 箭头指示 ↑ | `glow-pulse-strong` 1x |
| 降级技能 | amber 脉冲 + 箭头指示 ↓ | `glow-pulse` 1x |
| 需求上升 | 边框渐变为 cyan | `border-color` 过渡 0.5s |
| 需求下降 | 边框渐变为 rose | `border-color` 过渡 0.5s |

```
┌──────────────────────────────────────────────────────────┐
│  对比时间: [2023 Q1 ▾]  ←→  [2026 Q3 ▾]    [交换] [关闭] │
├─────────────────────┬────────────────────────────────────┤
│  2023 Q1 (基准)      │  2026 Q3 (当前)                     │
│                     │                                    │
│  ┌─────────────┐    │  ┌─────────────┐                   │
│  │ 🟢 Python   │    │  │ 🟢 Python   │ (不变)             │
│  │ 🟢 深度学习  │    │  │ 🟢 深度学习  │ (不变)             │
│  │ 🟡 SVM      │    │  │ 🔴 SVM      │ → 删除             │
│  │ 🟡 统计学习  │    │  │ 🟡 统计学习  │ (不变)             │
│  │            │    │  │ 🟢 LLM 应用  │ ← 新增 + mint辉光   │
│  │            │    │  │ 🟢 MLOps     │ ← 新增 + mint辉光   │
│  └─────────────┘    │  └─────────────┘                   │
│                     │                                    │
│  技能数: 4          │  技能数: 6                          │
│  市场需求: 72%      │  市场需求: 94% ↑                    │
├─────────────────────┴────────────────────────────────────┤
│  变化汇总: +2 新增  -1 删除  0 升级  2 不变               │
```

- 连线动画：共同技能之间有短暂的连接线扫过

## 3. 置信度与数据溯源系统

### 3.1 ConfidenceBadge 组件（新增）

在每项 AI 生成内容旁显示置信度，用颜色编码：

| 置信度 | 样式 | 含义 |
|--------|-----|------|
| ≥85% | `mint` 实线 + ✓ | 高置信，可直接采纳 |
| 60-85% | `amber` 虚线 + ⚠ | 需人工复核 |
| <60% | `rose` 点状边框 + ✗ | 可能含幻觉，不建议直接使用 |

### 3.2 DataSource 标注行

每个数据卡片底部增加数据溯源行：
```html
<div class="text-xs text-muted mt-2 pt-2 border-t border-border">
  📊 数据源: 招聘JD(352份) · 行业报告(8份) · 课程大纲(15份)
  🕐 更新时间: 2026-08-03
  🎯 置信度: <ConfidenceBadge :level="87" />
</div>
```

## 5. 企业仪表板增强

### 5.1 HUD 动态数值

六格 HUD 改为带动画过渡的计数器：

- 数值变化时使用 `countUp` 动画（从旧值滚动到新值）
- 背景 pulse 动画配合数值变化
- 趋势箭头 ↑↓ 带颜色编码（mint ↑, rose ↓）

### 5.2 实时脉冲通知

当系统检测到变化时（静态 demo 可模拟）：
- 对应岗位卡片发出 `heartbeat-pulse` 动画
- HUD 对应指标框闪烁一次
- 如有全局通知，顶部出现 toast bar

### 5.3 全局通知条组件（新增）

## 6. 全景图谱增强（GraphView）

企业侧 `/enterprise/graph` 需要三种视图切换：

| 视图 | 节点着色 | 节点大小 | 连线含义 |
|------|---------|---------|---------|
| **技术栈视图** | 按领域（AI/前端/后端/数据/DevOps） | 技能数量 | 岗位-技能归属 |
| **级别视图** | 按 P5→P8 渐变 | 市场需求 | 岗位层级关系 |
| **热度视图** | mint→amber→rose（热度从高到低） | 需求指数 | 技能相关性 |
