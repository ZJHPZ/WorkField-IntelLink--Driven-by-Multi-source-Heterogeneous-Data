## 1. 色彩系统映射

### 1.1 数知原始配色 → 职域智联适配

| 数知用途 | 数知色值 | 职域智联用途 | 保持不变？ |
|---------|---------|-------------|----------|
| 虚空底色 | `#050510` → `#0a0a18` | 全局背景 | ✅ 完全一致 |
| 靛蓝品牌色 | `#6366f1` (主), `#818cf8` (亮), `#4f46e5` (暗) | 主交互色（按钮、链接、进度） | ✅ 完全一致 |
| 青色强调色 | `#06b6d4` | 企业侧："已确认"状态 / 个人侧："已匹配"技能 | ✅ 完全一致 |
| 紫色点缀 | `#a855f7` | 渐变过渡色、AI思考态 | ✅ 完全一致 |
| 薄荷绿 | `#10b981` | 企业侧："已验证通过" / 个人侧："技能健康" | ✅ 完全一致 |
| 琥珀色 | `#f59e0b` | 企业侧："待验证" / 个人侧："保鲜预警" | ✅ 完全一致 |

### 1.2 主题切换：`data-theme` 属性而非 `dark:` 变体

```
职域智联复用策略：
- 同样采用 data-theme="dark"|"light" 属性
- 系统性地覆盖 Tailwind bg-white/text-gray-* 到深色变量
- 使用 CSS 自定义属性定义色板：
  --bg-primary, --bg-card, --text-primary, --text-secondary, --border-color
```

## 2. 企业侧 页面风格映射

### 2.1 仪表板 → 企业工作台主页

| 数知参考 | 职域智联企业侧适配 |
|---------|-----------------|
| `Dashboard.vue` 欢迎横幅 | "岗位标准智能管理平台" 标题 + 品牌渐变背景 + 毛玻璃数字面板 |
| HUD 状态条（6列） | 企业 HUD：已管理岗位数 / 待验证新岗位 / JD 审计通过率 / 市场变化预警 / 团队覆盖率 / 上次更新时间 |
| ECharts 柱状图 | 技能新兴度/衰退度 Top 10 柱状图 |
| 双栏布局 | 左栏：岗位演化时间轴 / 右栏：新岗位发现列表 |

**企业 HUD 状态条设计**：
```
┌──────────────────────────────────────────────────────────────┐
│  [图标] 12个岗位   [图标] 3个待验证   [图标] 85%通过率       │
│  [图标] 2项预警     [图标] 72%覆盖率   [图标] 2026-08-03     │
└──────────────────────────────────────────────────────────────┘
```
每个格：SVG 图标 + 数值 + 趋势箭头（↑↓）+ hover 时高亮 + tooltip

### 2.2 岗位演化时间轴 → `StageCard.vue` 模式

| 数知状态 | 职域智联企业侧映射 |
|---------|-----------------|
| `completed` (绿色边框 + 薄荷背景) | 技能"已确认"——深绿边框 + 淡淡薄荷色 |
| `in_progress` (品牌色辉光) | 技能"新兴/上升"——靛蓝色辉光 + `shadow-brand-500/10` |
| `available` (标准) | 技能"稳定"——浅灰边框 + 白色 |
| `locked` (淡出) | 技能"衰退"——灰色 + `opacity-60` |

### 2.3 新岗位发现 → `StageCompleteModal.vue` 模式

当候选岗位通过验证（Confirmed）时：
```
- 全屏 Teleport to body + bg-black/60 backdrop-blur-sm 遮罩
- 40 片彩纸粒子（CSS confetti-fall 动画）
- 中心发光图标：靛蓝→紫→青渐变
- 5 字段定义以卡片网格展示
- 弹性缩放入场（cubic-bezier(0.34, 1.56, 0.64, 1) 0.4s）
```

### 2.4 JD 诊断报告 → `EnergyBar.vue` 模式

```
通胀指数展示为多色进度条：
- 0.0-0.3: 薄荷绿（健康）
- 0.3-0.5: 琥珀色（需关注）
- 0.5-1.0: 玫瑰色（严重注水）

使用 EnergyBar 的 brand/mint/amber/rose 五变体
```

## 3. 个人侧 页面风格映射

### 3.1 技能画像 → `ProfilePanel.vue` 模式

```
- 6 维能力雷达图（对应学习画像的 6 维度）
  改为：技能覆盖度 / 匹配率 / 保鲜健康度 / 新兴技能占比 / 深度 / 广度
- AI 摘要卡片："基于你的 12 项技能，最强方向是..."
- CSS radial-gradient 辉光围绕核心技能
```

### 3.2 人岗匹配 → `ProgressRing.vue` 模式

```
匹配率展示为 SVG 圆形进度环：
- 使用靛蓝→紫→青渐变
- 圆角端点
- 弹入动画（0.8s cubic-bezier）
- 中心显示匹配百分比

缺失技能列表 = 红色高亮（评委一眼看懂扣分项）
```

### 3.3 学习路径 → `StageCard.vue` 模式

```
每个学习步骤 = 一张 StageCard：
- Step 1 (进行中): 品牌色辉光 + shadow-brand-500/10
- Step 2-3 (待开始): 标准白卡
- Step 完成: 薄荷绿边框

级联入场动画：每张卡片递进 60ms 延迟
```

### 3.4 技能保鲜 → `FocusLighthouse.vue` 模式

```
"保鲜健康度"灯塔可视化：
- 光束高度 = 健康技能占比 (0-100%)
- 光束颜色：绿（>80%）→ 靛蓝（50-80%）→ 琥珀（30-50%）→ 玫瑰（<30%）
- 预警技能标记在灯塔刻度上（25%/50%/75%/100% 虚线）
```

### 3.5 转行可行性 → `ProfileStar3D.vue` 概念映射

```
不用 3D，但复用"重叠区域"的视觉隐喻：
- 两个圆的交集 = 可复用技能（薄荷绿）
- 左圆独有 = 将被废弃（灰/淡出）
- 右圆独有 = 需新学（琥珀色标记）
- 交集大小 = Jaccard 相似度 → 可行性评级
```

## 4. 共享 UI 组件映射

### 4.1 背景系统 → `CosmicBackground.vue` 完全复用

```
企业侧和个人侧共用同一个宇宙背景组件：
- 深色底色：三层 radial-gradient（#1a1040 → #0a0a18 → #050510）
- 星云光晕：4 个靛蓝/青/紫/薄荷绿超大模糊圆
- 星空：80 个 CSS 粒子（确定性放置，防闪烁）
- 数据光线：极淡扫描线（opacity 6%，8-12s 滑动）
- 漂移光斑：2 个超大模糊圆（blur-3xl，20-25s 漂移）
```

### 4.2 全局 CSS → `global.css` 直接复刻

```
必须复刻的 CSS 类：
.glass-card          — 内容卡片（bg-card + backdrop-blur(12px)）
.glass-card-dark     — 模态框/弹窗（更暗的半透明）
.text-gradient-brand — 品牌渐变文字
.bg-brand-gradient   — 品牌渐变背景（indigo→indigo-light→cyan）
.bg-energy-gradient  — 能量渐变进度条
.shimmer-effect      — 光泽扫过效果
.slide-up-enter-active — 弹性缩放入场 (cubic-bezier(0.34, 1.56, 0.64, 1))

必须复刻的 keyframe：
springIn, bounceIn, shimmer-sweep, glow-pulse, glow-pulse-strong,
achievement-unlock, heartbeat-pulse, beam-breathe, confetti-fall
```

### 4.3 动画词汇表

```
页面过渡:   cubic-bezier(0.34, 1.56, 0.64, 1) 0.4s (弹性)
列表交错:   每个子元素 +60ms 延迟（最多 8 个）
进度条:     transition-all duration-700（填充感）
光晕脉冲:   3s ease-in-out（品牌元素呼吸）
光晕强化:   2s 双层 box-shadow（卡片悬停）
星空闪烁:   3s ease-in-out, opacity 0.4↔1.0（装饰）
按钮涟漪:   0.3s 径向渐变叠加（点击反馈）
```

## 5. 架构模式映射

### 5.1 双角色演示 → 企业/个人模式切换

```
数知方式: localStorage user_id → default_user/admin_user
职域智联适配:
  顶层导航切换"企业工作台" / "个人工作台"
  → 前端路由完全分叉（/enterprise/* vs /personal/*）
  → 后端 API 路径独立（/api/enterprise/* vs /api/personal/*）
  → 共享基地 API（/api/graph, /api/metrics）两端可调
```

### 5.2 API 静默回退

```
数知方式: try { data = await api.get() } catch { data = demoData }
职域智联适配:
  企业侧演示数据: 3 个岗位标准 + 10 条JD + 差异报告
  个人侧演示数据: 1 份简历 + 3 个目标岗位 + 匹配结果
  → 确保前端无后端也能完美展示所有功能
```

### 5.3 智能体状态叙事化

```
数知 way: 文案池 + 去重轮换 + 聚合文案

职域智联适配:
  企业侧文案池:
    "系统正在扫描市场JD数据..."
    "DiscoveryAgent 正在分析新兴技能聚类..."
    "JudgeAgent 正在审核候选岗位..."
    "正在生成差异报告..."

  个人侧文案池:
    "ExtractAgent 正在解析您的简历..."
    "MatchAgent 正在匹配目标岗位..."
    "SuggestAgent 正在规划学习路径..."
    "正在生成保鲜提醒..."
```
