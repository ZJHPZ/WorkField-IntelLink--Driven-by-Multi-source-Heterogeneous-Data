# 「数知」前端可视化 — 数据需求说明文档

> 本文档梳理前端所有可视化元素所需的数据字段、数据结构、数据来源及当前状态（Mock/需对接），作为后端 API 开发和数据对接的依据。

## 一、数据总览

### 1.1 数据来源分类

| 来源 | 说明 |
|------|------|
| **用户数据** | 用户基本信息、等级经验、成就徽章、学习统计 |
| **学习路径数据** | 阶段规划、进度、知识点掌握度 |
| **复习数据** | 遗忘曲线、复习队列、保留率 |
| **知识图谱数据** | 知识点节点、分类、掌握状态、依赖关系 |
| **练习数据** | 题库、答题记录、得分统计 |
| **AI 对话数据** | 会话历史、消息流 |
| **周报数据** | 每周学习汇总、排行变化 |

### 1.2 当前状态标识

| 标记 | 含义 |
|------|------|
| ✅ 已对接 | 通过 API 获取真实数据 |
| 🔶 Mock | 前端硬编码演示数据，需替换为 API |
| ❌ 未实现 | UI 占位但无任何数据逻辑 |

### 2.4 心流状态 (FlowState)


| `bored` | 28% | warning-500 | 💤 内容偏简单，建议提升难度 |
| `frustrated` | 92% | danger-500 | 😰 内容偏难，建议回顾前置知识 |

**需要数据**（当前全部硬编码）：
| 字段 | 类型 | 说明 | 状态 |

| 参与度 | `number` | 0-100% | 🔶 硬编码 78% |
| 难度匹配 | `number` | 0-100% | 🔶 硬编码 82% |
| 完成率 | `number` | 0-100% | 🔶 硬编码 65% |

## 十、关键注意事项

1. **知识图谱的边（links）**：当前仅简单连接各分类首节点，实际需要后端返回完整的知识点前置依赖关系。
2. **心流状态**：3 个指标（参与度/难度匹配/完成率）目前硬编码在 `FlowState.vue` 中，需要改为 props 或 store 数据。
3. **练习中心**：所有题目均为硬编码的 HDFS 样板题，题库选择虽然 UI 支持切换，但实际不区分。
4. **设置页**：昵称/邮箱/每日目标均为只读展示，没有保存 API 调用。
5. **Dashboard 初始化**：`App.vue` 的 `onMounted` 中调用了 `fetchAchievements()`、`fetchReviews()`、`fetchTopicMastery()`，但 Dashboard 自身额外调用了 `fetchLearningPath()`，初始化流程分散。
6. **所有带 `🔶 Mock` 标记的数据**都位于对应 Store 的 `fetch*` 方法中，替换为真实 API 调用即可。
