# 智能体对话问题分析报告

## 一、问题描述

**现象：** 智能体在对话中出现"答非所问"的情况，用户提出具体问题后，智能体返回通用问候语，没有回答用户的问题。

**影响：** 用户无法获得有效的问答服务，影响用户体验。

---

## 二、测试验证

### 测试1：Spark技术问答

| 项目 | 内容 |
|-----|------|
| **用户问题** | `"什么是Spark？请简要介绍Spark的核心特点"` |
| **期望回复** | 介绍Spark的定义、核心特点（如RDD、DAG执行引擎、内存计算等） |
| **实际回复** | `"你好呀！我是你的专属大数据学习伙伴...你现在想学什么呢？"` |

**结果：❌ 答非所问**

### 测试2：图片理解（已验证）

| 项目 | 内容 |
|-----|------|
| **用户问题** | `"这张图里讲了什么？请描述图片内容"` |
| **期望回复** | 分析图片内容 |
| **实际回复** | 智能体调用图片分析工具，Vision API返回401错误后fallback到图片描述 |

**结果：⚠️ 工具触发成功，但Vision API配置问题**

### 问题层级定位

| 层级 | 状态 | 说明 |
|-----|------|------|
| **前端→工作流** | ✅ 正确 | 用户输入正确传递 |
| **工作流→智能体API** | ✅ 正确 | query字段正确传递 |
| **智能体系统处理** | ❌ **问题所在** | 收到query但没有正确响应 |

## 四、问题原因分析

### 可能原因

| 原因 | 说明 | 优先级 |
|-----|------|--------|
| **System Prompt设计问题** | 智能体过度强调"学习伙伴"角色，优先输出问候语 | 高 |
| **意图识别问题** | 智能体没有区分"提问"和"开始学习"两种场景 | 高 |
| **触发规则问题** | 新session_id可能触发"欢迎流程"，覆盖问答流程 | 中 |
| **模型响应问题** | 模型可能对技术问题的理解能力不足 | 低 |

### 根因推断

智能体的System Prompt可能包含以下内容：
- "我是你的专属大数据学习伙伴"
- "告诉我你想学什么"

这导致智能体在**任何输入**下都优先输出问候语和引导语，而不是直接回答用户的问题。

---

## 五、建议修复方案

### 1. 优化System Prompt

**建议增加以下指令：**

```
## 问答优先原则
- 当用户直接提出技术问题时，优先回答问题，不要输出问候语
- 问候语仅在用户打招呼或首次对话时使用
- 判断用户意图：
  - 如果query包含"是什么"、"如何"、"为什么"、"特点"、"区别"等疑问词 → 直接回答
  - 如果query是"你好"、"我想学习"等 → 输出问候和引导
```

### 2. 增加意图判断逻辑

在智能体系统端增加前置判断：

```python
def detect_intent(query: str) -> str:
    """判断用户意图"""
    question_keywords = ["是什么", "如何", "为什么", "特点", "区别", "介绍", "讲解", "解释"]
    greeting_keywords = ["你好", "您好", "我想学习", "开始学习"]
    
    for kw in question_keywords:
        if kw in query:
            return "question"  # 问答场景
    
    for kw in greeting_keywords:
        if kw in query:
            return "greeting"  # 问候场景
    
    return "question"  # 默认视为问答场景
```

### 3. 调整响应优先级

| 场景 | 优先级 | 响应策略 |
|-----|--------|---------|
| 问答场景 | **高** | 直接回答问题，不输出问候语 |
| 问候场景 | 中 | 输出问候语 + 引导学习方向 |
| 空输入 | 低 | 输出欢迎语 + 介绍功能 |

## 六、验证方法

### 修复后测试用例

| 测试编号 | 用户输入 | 期望输出 |
|---------|---------|---------|
| T1 | `"什么是Spark？"` | Spark的定义和核心特点介绍 |
| T2 | `"Hadoop和Spark有什么区别？"` | 对比分析两种技术 |
| T3 | `"你好"` | 问候语 + 引导学习方向 |
| T4 | `"我想学习大数据"` | 学习引导 + 推荐学习路径 |

### 验证标准

- T1、T2：回复内容应包含技术信息，不应以问候语开头
- T3、T4：回复内容应包含问候和引导
- 所有测试：回复应与用户意图匹配
