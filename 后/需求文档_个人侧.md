## 2. 数据模型

### 2.1 UserSkillProfile（个人技能档案）

> 存储于 MySQL `user_skill_profiles`。每次上传简历自动更新，保留时间戳形成成长轨迹。

```sql
CREATE TABLE user_skill_profiles (
    id              INT PRIMARY KEY AUTO_INCREMENT,
    user_id         VARCHAR(64) NOT NULL,
    resume_id       VARCHAR(64),                       -- 最近一次简历 ID
    raw_text        TEXT,                               -- 简历原文（截断5000字）
    created_at      DATETIME DEFAULT NOW(),
    updated_at      DATETIME DEFAULT NOW(),
    INDEX idx_user (user_id)
);

CREATE TABLE user_skills (
    id              INT PRIMARY KEY AUTO_INCREMENT,
    profile_id      INT NOT NULL,
    skill_name      VARCHAR(128) NOT NULL,             -- 原始技能名
    skill_canonical VARCHAR(128) NOT NULL,             -- 归一化后的规范名
    category        ENUM('hard','tool','framework','soft') DEFAULT 'hard',
    level           ENUM('L1','L2','L3') DEFAULT 'L3', -- 技能级别
    first_seen      DATETIME DEFAULT NOW(),            -- 首次出现在简历中
    last_seen       DATETIME DEFAULT NOW(),            -- 最近一次出现
    occurrence_count INT DEFAULT 1,                    -- 历史出现次数
    extraction_source VARCHAR(16) DEFAULT 'rule',      -- spark / rule
    FOREIGN KEY (profile_id) REFERENCES user_skill_profiles(id),
    INDEX idx_canonical (skill_canonical),
    INDEX idx_profile (profile_id)
);

CREATE TABLE match_history (
    id              INT PRIMARY KEY AUTO_INCREMENT,
    user_id         VARCHAR(64) NOT NULL,
    position_id     VARCHAR(64) NOT NULL,
    position_name   VARCHAR(256),
    match_rate      DECIMAL(4,3) NOT NULL,
    matched_count   INT DEFAULT 0,
    missing_count   INT DEFAULT 0,
    matched_skills  JSON,
    missing_skills  JSON,
    created_at      DATETIME DEFAULT NOW(),
    INDEX idx_user_pos (user_id, position_id)
);
```

### 2.2 技能画像时间轴

```
user_skills 表的 first_seen / last_seen 构成成长追踪:

  2024-03: 首次上传简历 → {Python, SQL, Git} (3项)
  2025-01: 第二次上传   → {Python, SQL, Git, PyTorch, Docker} (5项, +2)
  2026-08: 第三次上传   → {Python, SQL, Git, PyTorch, Docker, RAG, Transformer} (7项, +2)

可视化: 每次上传的时间戳 + 新增技能高亮
```

### FR-2 人岗匹配

#### FR-2.1 单岗位匹配

```
API: POST /api/match

Request:
{
  "user_skills": ["Python", "PyTorch", "SQL", "Docker", "Git", "Linux", "Transformer", "RAG"],
  "position_skills": [
    {"name": "Python",      "required_type": "必备", "confidence": 0.95},
    {"name": "PyTorch",     "required_type": "必备", "confidence": 0.92},
    {"name": "Transformer", "required_type": "必备", "confidence": 0.88},
    {"name": "大模型微调",  "required_type": "必备", "confidence": 0.85},
    {"name": "RAG",         "required_type": "必备", "confidence": 0.82},
    {"name": "DeepSpeed",   "required_type": "加分", "confidence": 0.70},
    {"name": "Docker",      "required_type": "加分", "confidence": 0.68}
  ],
  "position_name": "AI工程师"
}

匹配算法 (match_service.match_skills):

  1. 技能归一化: normalize_name() 消除别名差异
  2. 完全匹配: 用户技能名 == 岗位要求名 → matched
  3. 模糊匹配: 子串包含 → partial (权重 0.5)
  4. 缺失技能: 岗位要求中不在用户集且无模糊匹配的

  匹配率公式:
    skill_coverage = (matched_count + partial_count * 0.5) / total_required
    required_rate  = (matched_required + partial_required * 0.5) / total_required
    match_rate     = skill_coverage * 0.4 + required_rate * 0.6

  优先级判定:
    - 高: 必备 + 置信度 > 0.6
    - 中: 必备但置信度低，或加分但市场热度高
    - 低: 加分项

Response:
{
  "status": "ok",
  "position_name": "AI工程师",
  "match_rate": 0.72,
  "skill_coverage": 0.75,
  "matched_skills": ["Python", "PyTorch", "Transformer", "RAG", "Docker"],
  "partial_skills": [],
  "missing_skills": [
    {"name": "大模型微调", "canonical": "大模型微调", "priority": "高", 
     "required_type": "必备", "confidence": 0.85, "reason": "岗位必备技能"},
    {"name": "DeepSpeed",  "canonical": "DeepSpeed",  "priority": "低",
     "required_type": "加分", "confidence": 0.70, "reason": "加分技能"}
  ],
  "learning_path": [
    {"step": 1, "skill": "大模型微调", "priority": "高", "duration": "3-4个月",
     "resources": ["搜索 'LoRA 微调教程'", "HuggingFace PEFT 文档"]},
    {"step": 2, "skill": "DeepSpeed",  "priority": "低", "duration": "2-3个月",
     "resources": ["DeepSpeed 官方文档"]}
  ],
  "agent_id": "matcher"
}
```

#### FR-3.2 学习路径生成逻辑

```
1. 按优先级排序缺失技能（高 > 中 > 低）
2. 检测前置依赖:
   - LoRA 需要 PyTorch → 如果用户不会 PyTorch，先学 PyTorch
   - RAG 需要 Python → 如果用户不会 Python，先学 Python
3. LLM (SuggestAgent) 生成详细路径:
   - System Prompt: "你是职业规划专家..."
   - Input: 缺失技能列表 + 用户现有技能 + 目标岗位
   - Output: 分步骤学习路径 + 资源推荐
4. 估算每步时间:
   - 高优先级必备: 3-4个月
   - 中优先级: 2-3个月
   - 低优先级: 1-2个月
```

### FR-5 转行可行性分析

```
API: POST /api/personal/career/switch-feasibility

Request:
{
  "from_skills": ["Java", "Spring Boot", "MySQL", "Linux", "Git"],
  "to_skills":   ["Python", "PyTorch", "Spark", "Hadoop", "SQL", "Linux", "Git"],
  "from_name": "Java后端",
  "to_name": "大数据工程师"
}

算法:
  1. 计算 Jaccard 相似度 = |from ∩ to| / |from ∪ to|
  2. 分类技能:
     - overlap (可复用): from ∩ to
     - need_to_learn (需新学): to - from
     - will_be_deprecated (将被废弃): from - to
  3. 可行性判定:
     - Jaccard >= 0.6 → "高"
     - Jaccard >= 0.3 → "中"
     - Jaccard < 0.3  → "低"

Response:
{
  "from_position": "Java后端",
  "to_position": "大数据工程师",
  "jaccard_similarity": 0.27,
  "overlap_skills": ["MySQL", "Linux", "Git"],
  "overlap_count": 3,
```

## 4. Agent 编排

### 4.1 个人侧 Agent 调用链

```
FR-1 简历解析:
  POST /api/resume/parse
    → MultiAgentSystem.process(IntentType.EXTRACT_SKILLS, payload)
      → ExtractAgent.process(state)    [LLM: 星火抽取技能]
    → 返回 skills[]

FR-2 人岗匹配:
  POST /api/match
    → MultiAgentSystem.process(IntentType.MATCH_POSITION, payload)
      → MatchAgent.process(state)      [纯算法: Jaccard + 加权]
    → 返回 match_rate + matched/missing skills

FR-3 差距分析 + 学习路径:
  POST /api/personal/career/gap
    → MultiAgentSystem.process(IntentType.MATCH_POSITION, payload)
      → MatchAgent.process(state)
    → MultiAgentSystem.process(IntentType.CAREER_GAP, payload)
      → SuggestAgent.process(state)    [LLM: 星火生成学习路径]
    → 返回 learning_path

FR-4 技能保鲜:
  POST /api/personal/career/skill-freshness
    → 纯算法: career_service.skill_freshness()
    → 不经过 Agent（确定性计算）
```

## 5. 数据库查询规范

### 5.1 Neo4j 关键查询

```cypher
// 查询岗位要求（个人侧用，只返回 confirmed 技能）
MATCH (p:Position {position_id: $pid})-[r:REQUIRES]->(s:Skill)
WHERE s.status = 'confirmed'
RETURN s.name, s.confidence, s.df, s.emergence, s.decline, r.required_type

// 查询技能市场热度
MATCH (s:Skill {name: $name})
RETURN s.df AS market_demand, s.emergence, s.decline, s.half_life

// 查询技能共现（用于学习路径前置依赖）
MATCH (a:Skill {name: $name})-[r:CO_OCCURS]-(b:Skill)
WHERE r.strength > 0.5
RETURN b.name, r.strength ORDER BY r.strength DESC LIMIT 10
```

### 5.2 MySQL 关键查询

```sql
-- 用户技能历史（成长轨迹）
SELECT skill_canonical, first_seen, last_seen, occurrence_count
FROM user_skills us
JOIN user_skill_profiles up ON us.profile_id = up.id
WHERE up.user_id = 'user-001'
ORDER BY first_seen;

-- 用户匹配历史
SELECT position_name, match_rate, created_at
FROM match_history
WHERE user_id = 'user-001'
ORDER BY created_at DESC LIMIT 20;
```
